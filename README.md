# Portfolio Starter — section terpisah dan scroll satu halaman

## Struktur
- `index.html`: halaman utama; jalankan file ini melalui Live Server.
- `html/`: isi masing-masing section.
- `css/main.css`: styling asli portfolio agar desain awal dipertahankan.
- `css/home.css`, `about.css`, dan seterusnya: tempat menambahkan styling khusus tiap section.
- `js/main.js`: memuat semua section ke satu halaman dan mengaktifkan navigasi, scroll, tema, dan menu.
- `js/home.js`, `about.js`, dan seterusnya: tempat menambahkan interaksi khusus section.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder utama project di VS Code.
3. Klik kanan `index.html` di root project, pilih **Open with Live Server**.
4. Jangan membuka file section secara langsung jika ingin melihat portfolio utuh.

`fetch()` membutuhkan server lokal (misalnya Live Server), jadi jangan jalankan dengan double-click `index.html`.
